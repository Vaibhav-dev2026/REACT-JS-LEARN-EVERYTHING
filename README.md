## ⚛️ What Is React.js?

React.js is an open-source JavaScript library used to build user interfaces, especially interactive web applications.

It allows developers to divide an application into smaller, reusable components instead of writing the entire interface as one large piece of code.

React helps developers manage changing data, update the user interface, and organise complex applications using a component-based approach.

**Some important features of React.js include:**

- Component-Based Architecture
- JSX (JavaScript XML)
- Reusable Components
- Props and State
- React Hooks
- Virtual DOM and Reconciliation
- Conditional Rendering
- Event Handling
- State Management
- One-Way Data Flow
- Component Lifecycle and Effects
- Declarative UI Development

Official Documentation: [React.dev](https://react.dev/)

## 💻 Running a React Application

The execution process depends on the particular React project and its configuration.

Follow these general steps when you find a React application inside the repository:

**Step 1: Open the project folder**

Open the folder containing the React application's `package.json` file.

**Step 2: Install dependencies**

Run `npm install` in the terminal from that project folder.

**Step 3: Start the development server**

Check the `scripts` section of `package.json` to identify the correct start command. For a Vite project, the usual command is `npm run dev`.

**Step 4: Open the application**

Open the local URL displayed in your terminal in your browser.

**Important:** Not every folder needs `npm install`. Run it only inside a project that has a `package.json` and requires its dependencies. Different projects may have different scripts.

## 📖 Recommended Learning Approach

To learn React effectively, follow a concept-based and practical learning approach.

**1. Understand JavaScript First**

React is built around JavaScript. Make sure you understand variables, functions, arrays, objects, promises, ES6+ features, and array methods.

**2. Learn React Fundamentals**

Start with JSX, components, props, state, and event handling.

**3. Practise Every Concept**

Create small examples to understand how each concept works.

**4. Understand Data Flow**

Learn how information moves between parent and child components and how state updates affect the user interface.

**5. Learn React Hooks**

Understand the purpose and practical usage of the important React Hooks.

**6. Work with APIs**

Practise retrieving data from external APIs and displaying it in React components.

**7. Build Projects**

Apply different concepts together by creating practical applications.

**8. Revise and Debug**

Revisit previously learned concepts, understand errors, and improve your code.

## 💡 Best Practices to Follow

While learning and developing React applications, keep these principles in mind:

- Use meaningful component and variable names.
- Keep components small and reusable.
- Follow the Rules of Hooks.
- Never modify state directly.
- Use proper and stable keys when rendering lists.
- Keep components focused on clear responsibilities.
- Avoid unnecessary state variables.
- Use props for passing data between components.
- Use Context or other state management approaches when appropriate.
- Handle loading and error states when working with APIs.
- Keep application logic organised.
- Avoid unnecessary re-renders.
- Write clean and readable JSX.
- Understand the code before copying it.
- Prefer official documentation when learning new React features.
